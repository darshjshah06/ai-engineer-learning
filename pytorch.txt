PyTorch is a deep learning library

PyTorch's three main components include:
tensor library as a fundamental building block for computing, great for switch from GPU and CPU
automatic differentiation for model optimization
deep learning utility functions, making it easier to implement and train deep neural network models


tensors ----------------


tensor(s) are mathematical objects that can be characterized by their order (or rank)
PyTorch tensors are data containers for array-like structures

autograd -------------------------


PyTorch’s autograd system provides functions to compute gradients in dynamic computational graphs automatically. 

import torch.nn.functional as F

y = torch.tensor([1.0])  # true label
x1 = torch.tensor([1.1]) # input feature
w1 = torch.tensor([2.2]) # weight parameter
b = torch.tensor([0.0])  # bias unit

z = x1 * w1 + b          # net input
a = torch.sigmoid(z)     # activation & output for Neural Network, aka turns everything in range 0-1.

loss = F.binary_cross_entropy(a, y)
print(loss)

#output 
tensor(0.0852)



automatic differentiation -------------------
 
Gradients are required when training neural networks via the popular backpropagation algorithm
which can be thought of as an implementation of the chain rule from calculus for neural networks
are required when training neural networks via the popular backpropagation algorithm

The chain rule is a way to compute gradients of a loss function with respect to the model’s parameters 
in a computation graph. This provides the information needed to update each parameter in a way that 
minimizes the loss function, which serves as a proxy for measuring the model’s performance,
using a method such as gradient descent.

import torch.nn.functional as F
from torch.autograd import grad

y = torch.tensor([1.0])
x1 = torch.tensor([1.1])
w1 = torch.tensor([2.2], requires_grad=True) #Track operations involving this tensor so gradients can be computed later.
b = torch.tensor([0.0], requires_grad=True)  # same here

z = x1 * w1 + b
a = torch.sigmoid(z)

loss = F.binary_cross_entropy(a, y)

grad_L_w1 = grad(loss, w1, retain_graph=True) 
grad_L_b = grad(loss, b, retain_graph=True)

print(grad_L_w1) # simpler way explained later
print(grad_L_b)  # same here

#output

(tensor([-0.0898]),)
(tensor([-0.0817]),)


# what is above is the "manual" way to do it. But PyTorch provides a higher level tool to automate,
we can call the .backward on the loss and the gradient will compute the gradient of all the leaf nodes,
which will be stored via the tensors' .grad

loss.backward()
print(w1.grad)
print(b.grad)

#output
tensor([-0.0898])
tensor([-0.0817])



implementing multiplayer -------------------------------


class NeuralNetwork(torch.nn.Module):     #torch.nn.module makes it easier to build and train models
    def __init__(self, num_inputs, num_outputs):
        super().__init__()

        self.layers = torch.nn.Sequential(

            # 1st hidden layer
            torch.nn.Linear(num_inputs, 30),
            torch.nn.ReLU(),

            # 2nd hidden layer
            torch.nn.Linear(30, 20),
            torch.nn.ReLU(),

            # output layer
            torch.nn.Linear(20, num_outputs),
        )

    def forward(self, x):      # how the input data passes through the network and comes together as a computation graph
        logits = self.layers(x)
        return logits

model = NeuralNetwork(50, 3)   #instantiate a new neural network object
